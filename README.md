# Sonali Kesarwani — Personal Legal Portfolio

A responsive, single-page professional identity website built with semantic HTML, CSS, and vanilla JavaScript. It has no build step or package dependencies.

## Preview locally

1. Extract this folder.
2. Open `index.html` in a modern browser, or serve the folder with any static web server.

## Before publishing

- Confirm whether the two internship descriptions are distinct experiences or refer to the same internship. If they are the same, merge the timeline entries.
- The confirmed WhatsApp number is configured in `index.html` as `918707702564` (India country code included, digits only). The WhatsApp contact links are enabled.
- The contact form validates fields in the browser and opens the visitor's default email app with a prefilled email. It does not submit to a server, store submissions, or show a false server-side success. For a production form that submits directly, connect a backend or trusted form service and configure spam protection.
- Replace or extend Open Graph metadata with the deployed canonical URL and a real social-sharing image after hosting.
- Google Fonts are loaded remotely; system serif/sans fallbacks are provided.

## Design notes

- Palette: navy `#142B4A`, midnight `#0B1F36`, beige `#E8D8C3`, ivory `#FAF8F3`, champagne gold `#B89A67`.
- Responsive mobile navigation, skip link, keyboard focus states, reduced-motion support, section reveal transitions, and dynamically updated copyright year are included.
- No portrait is fabricated; the hero uses a custom abstract courthouse-inspired SVG illustration.
- The content intentionally avoids claiming advocate enrollment, licensed practice, specialist status, case results, testimonials, or unverified social profiles.
